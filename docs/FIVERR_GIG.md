# Fiverr gig copy (English)

**Title:** I will build an AI agent that routes between your PDFs and live web search (RAG)

**Description:**
I build production-ready RAG agents with LangGraph. Your assistant reads your uploaded PDFs (Pinecone vector search) and decides on its own when a question needs live web results (Tavily) instead, then answers with citations.

What you get:
- LangGraph agent with smart routing: PDFs, web, or direct answer
- Automatic fallback to web search when the documents have no answer
- PDF upload, chunking, embeddings and Pinecone indexing
- ChatGPT-style Next.js (TypeScript, Tailwind) chat UI with streaming and source cards
- FastAPI backend, clean folder structure, Docker support, setup guide
- Works with any model via OpenRouter

**Packages**
- Basic: backend agent + API, PDF indexing, docs
- Standard: Basic + Next.js chat UI, streaming, citations
- Premium: Standard + deployment (Vercel + Railway/Render), custom branding, 14 days support

**Requirements to start:** your API keys (OpenRouter, Pinecone, Tavily) or I can use test keys, plus a sample PDF.
